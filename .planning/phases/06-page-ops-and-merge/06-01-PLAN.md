<interfaces>
New exports, fixed for downstream plans (indices are zero-based in modules; UI is one-based):
All structural saves preserve existing form appearances via save({updateFieldAppearances:false}); no automatic field flattening or appearance regeneration. Worker-only browser invocation is required by 05.
- loadLocalPdf(bytes, {password}) -> Promise PDFDocument; no ignoreEncryption bypass.
- describePage(pdf, index) -> {mediaBox:{x,y,width,height}, cropBox:{x,y,width,height}, userUnit, rotation, visibleWidth, visibleHeight}; visible dimensions are physical points over CropBox intersected with MediaBox, matching pdf.js scale-1 viewport.
- inspectLocalPdf(bytes, {password}) -> {pageCount, pages, signed, encrypted}; signed includes SigFlags bit 1 and inherited FT=Sig with V, with depth 64 and 100,000-node traversal bounds.
- isolatePageResources(page) -> void; clone resolved Resources and each mutable Font/XObject/ExtGState/ColorSpace/Pattern/Shading/Properties dictionary before mutation; referenced streams remain immutable.
- transformPages(bytes, command, {password,acknowledged:false}) -> Promise {bytes, selectedPage, notices}; commands insertBlank {adjacentIndex,position}, move {from,to}, rotate {index,quarterTurns}, delete {index}. Fail closed on unknown signature state or unacknowledged signatures before every transform; return named refusals for unsafe catalog graph or final-page deletion.
- DocumentSnapshot = {bytes,sourceBytes,password,recipe,selectedPage,style,selection,localMetadata,analysis,findState,acknowledged,action}; localMetadata independently stores signed/encrypted/geometry/page count. analysis = {enabled,sourceIdentity,meta,index}, never controllers, promises, jobs or PDF proxies. Opened-original bytes are separately immutable for the lifetime of the file.
- captureSnapshot(state), admitHistory({openedBytes,current,history,candidateBytes,temporaryBytes}), pushSnapshot(history,snapshot), peekSnapshot(history), popSnapshot(history); failed admission returns a named refusal and changes nothing.
- applyPageOperation({snapshot,transform,prepare,isCurrent,admit,commit}) -> Promise {status:'applied'|'refused'|'failed'|'stale',...}. commit(prepared,next,snapshot) is one synchronous publication callback; caller owns its existing mutation lock.
- runPdfJob({workerFactory,command,payload,signal,timeoutMs:30000}) -> Promise result; every terminal path terminates worker and removes handlers. App supplies the concrete module Worker in 05; Node tests inject a worker adapter. Copy/transfer only admitted disposable buffers, never detach opened/current/history data.
