# Phase 7 Export panel

**Status:** implementation contract from CONTEXT discretion and current UI; no repeated design approval required. Preserve the existing typography, neutral colors, teal primary actions, native form controls, inspector width and responsive Pages/Find layout.

- Add **Export** to the inspector panel switch, reachable without Analyze text. Keep current PDF/original download and Undo reachable. Export actions never apply document edits or add history entries.
- Format select: Compressed PDF, Flattened PDF, PNG, JPEG, Split PDF, Plain text, Markdown, HTML. Initial choice Compressed PDF. A visible location label follows the selected execution branch: **In this browser** for images/split; **Server** for compression/flatten/text formats. Preparing a pending text change may itself require the already-disclosed text server route; render that composite disclosure accurately.
- Compressed PDF: **Lossless structural compression** is default; unchecked **Downsample images (changes image quality)** is explicit. Explain that unsupported images are retained. Action **Prepare compressed PDF** produces actual output; show before/after bytes and savings (including zero/negative savings honestly), notices and **Download compressed PDF**. When downsampling is selected, show labeled Before/After canvases for the same chosen page from current and returned PDF bytes, with a page selector so all pages can be reviewed. Download appears only for the matching prepared result. No promise every file gets smaller.
- PNG/JPEG: current-page or all-pages ZIP choice; **Screen — 150 DPI**, **Print — 300 DPI**, and bounded custom DPI (72–600). Show page progress. Encode JPEG on white; PNG retains rendered transparency only when explicitly supported by the helper contract. Use deterministic safe filenames `page-0001.png`/`.jpg`. The DPI controls physical output pixel dimensions independent of screen DPR.
- Split PDF: **Every N pages** (default 1) or **Page groups**, e.g. `1-3;4;5-8`. Groups are nonempty, ordered, disjoint and in range; reject duplicates/overlap and show inline guidance before starting. Produce individual PDF download links and **Download all as ZIP**. Existing destinations/widgets follow the safe deletion policy; display notices and safe refusals.
- Flattened PDF: explain that annotation appearances become page content and supported fields stop being interactive. Show the shared signature acknowledgement before PDF rewrites when needed; show unlocked-copy notices for encrypted input. The server refuses content it cannot flatten safely.
- Text/Markdown/HTML: explicit server action independent of Analyze text consent; explain reading-order/format limitations and scanned pages without OCR. HTML is a downloadable escaped document, never injected into the application's DOM.
- Working/error/results states stay in the panel. Disable conflicting mutations while an export owns busy state; Cancel aborts export tasks and discards results. Closing/reopening, changing bytes/options or Undo clears stale results and preview resources. Preserve all current bytes/history on failure. Announce progress/results with polite live regions; errors use role alert. Restore focus to the panel's result or error heading.
- At 320px/760px, form fields and panel-switch items wrap without horizontal overflow; paired previews stack. Controls have labels, keyboard navigation, visible focus and existing minimum touch-target sizing. Use actual browser observations for rendering/download/network checks in 07-04.
