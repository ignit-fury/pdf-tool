<interfaces>
POST /exports currently accepts raw application/pdf bytes with operation, downsample and acknowledge_signature query keys. Existing artifact envelope has exactly data, media_type, filename, before_bytes, after_bytes, changed_images, notices, location. Preserve its shape for PDF/A: operation=pdfa, media_type=application/pdf, filename=archival.pdf, changed_images=0.
Fixed refusal transport: engine PdfaRefusal has public code PDFA_UNSUPPORTED and reason_id from the table below. Worker maps it to the listed fixed error code; server/errors.py allowlists those codes and server/isolation.py preserves them through its existing error normalization. API dispatch maps them to HTTP 422 detail {code:"PDFA_UNSUPPORTED",reason_id:<listed ID>}; no raw engine message is transported. Existing request() retains error.detail, so the browser reads error.detail.reason_id, allowlists it, and selects the listed literal safe reason inside the approved PDF/A-refusal copy. Password/signature/invalid-PDF errors retain their existing paths.
| Worker error code | Public reason_id | Literal safe reason |
|---|---|---|
| PDFA_FONT_MISSING | font-missing | A required font is not embedded. |
| PDFA_FONT_UNSUPPORTED | font-unsupported | This document uses an unsupported font format. |
| PDFA_FONT_INVALID | font-invalid | An embedded font cannot be used safely. |
| PDFA_COLOR_UNSUPPORTED | color-unsupported | This document uses unsupported color features. |
| PDFA_CONTENT_UNSUPPORTED | content-unsupported | This document contains unsupported content. |
| PDFA_STRUCTURE_UNSUPPORTED | structure-unsupported | This document uses unsupported PDF structures. |
| PDFA_METADATA_UNSUPPORTED | metadata-unsupported | This document contains unsupported metadata. |
| PDFA_VERSION_UNSUPPORTED | pdf-version | This PDF version is not supported for archival conversion. |
| PDFA_LIMIT | limit | This document exceeds the archival conversion limits. |
Unknown/missing engine reason maps to PDFA_CONTENT_UNSUPPORTED; unknown/missing API reason uses the same content-unsupported literal. An unrecognized worker error stays the existing WORKER_FAILED path. Never render or report the unrecognized value, PDF text, object names, paths or exception strings.
createExportController({getCurrent,request,...}).prepare(options) captures {session,bytes,version,retainedBytes}; invalidation aborts requests and revokes URLs. Keep this contract.
