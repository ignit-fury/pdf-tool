Required new contracts:
- JSON: `{version:'ucd-15.1.0-nfkd-fullfold-v1',unicode_version:'15.1.0',nfkd,casefold,combining}` with sparse decimal-codepoint keys, identity entries omitted and nonzero CCC only.
- Python `project_text(text, *, match_case=False) -> {text,spans}` and `project_search_text(text) -> {version,sensitive:{text,spans},folded:{text,spans}}`. JS `projectText(text,{matchCase=false}={})` and `projectSearchText(text)` return identical structures. Every normalized UTF-16 code unit has one `[sourceStart,sourceEnd)` span in source UTF-16 units.
- JS `findMatches(pages,query,{matchCase=false,wholeWords=false,recipe=[]}={}) -> Match[]`; `pages` is the cached one-based page map. `Match` contains `id,runId,page,runOrder,start,end,normalizedStart,normalizedEnd,text,before,after,state,reason,replaceable`. `start/end` slice CURRENT recipe-overlaid source text; `normalizedStart/end` distinguish visible partial-expansion occurrences. Results sort by page/run order/normalized start. IDs include the query/options identity, effective-text/recipe revision, run ID and occurrence span and remain stable as other pages arrive.
- `buildReplacementRecipe({pages,recipe,matches,excludedIds,replacement,fontFamily='',refusedRunIds=new Set()}) -> {recipe,changes,selectedCount,changedPages,unchangedCount}`. Each change is `{runId,page,before,after,matchIds}`. `recipe` is the entire candidate, not only batch overrides; excluded/refused runs retain their previous operations. No-op occurrences do not inflate selectedCount or create operations/history.
