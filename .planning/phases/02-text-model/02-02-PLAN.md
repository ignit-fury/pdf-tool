## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Fixture-construction scripts <-> existing corpus PDFs | Reads only files already committed to this repo; no untrusted network fetch |
| tools/measure_truetype_cmap_gaps.py <-> embedded TrueType font programs | Parses font-program bytes from corpus PDFs via fontTools, a third-party parser over binary data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-02-01 | Denial of Service | fontTools.ttLib.TTFont parsing a malformed/adversarial embedded font program | mitigate | Wrap the per-font TTFont load in a try/except recording a per-document failure row, matching harness/run_corpus_harness.py's "record, never crash the run" convention already established in this repo; corpus is locally-trusted but the pattern must survive a genuinely malformed embedded font |
| T-02-04 | Information Disclosure | Fixture-construction scripts and the cmap-gap measurement script both print structural facts only | accept | Neither script decodes or prints document body text; output is filenames, category labels, and cmap subtable tuples |
</threat_model>
