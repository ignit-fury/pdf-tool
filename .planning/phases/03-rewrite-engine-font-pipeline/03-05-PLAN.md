<objective>
Build the write side of `engine/fonts.py`: subset each bundled Liberation family over its
whole-recipe glyph union (FONT-02/D-13), shape replacement text twice -- once pre-subset to learn
needed glyphs, once post-subset to get final CIDs directly (Pattern 2/Pitfall 5) -- and assemble
the resulting Type0/CIDFontType2 font dictionary with a correct `/W` array (FONT-04/D-14) and a
generated `/ToUnicode` CMap (FONT-03), tagged with a fresh subset tag per family (FONT-05). Every
function in this file creates NEW pikepdf indirect objects only; none ever mutates the original
document's font objects (D-12), so untouched text elsewhere using the same BaseFont keeps
rendering correctly after this module runs (roadmap criterion 3), structurally rather than by
convention.

Purpose: this is the font-embedding half `engine/rewrite.py` (03-06, Wave 4) calls once per
substituted run's family, after 03-04's read side (mapping table, substitution trigger) has
already decided WHICH runs need a bundled font and WHICH family. 03-05 does not decide who
substitutes -- it only builds the correct, minimal, spec-shaped replacement font once the decision
is already made.

Output: `engine/fonts.py` write side (subsetting, shape-twice CID resolution, Type0/CIDFontType2 +
`/W` + `/ToUnicode` assembly), `tests/test_fonts.py` additions.
</objective>
