<objective>
Prove Gate G2a: replacing a run whose glyphs all already exist in the embedded subset (no
substitution needed -- that's G2b's job in 03-09) produces output that satisfies every clause of
the roadmap's own G2a criterion, using the real, already-executed 03-01..03-07 pipeline for the
first time end to end. This is the first plan in the phase that calls `engine.recipe.apply_recipe`
against a real fixture instead of a unit-level mock.

**The correction this plan implements.** ROADMAP.md's G2a criterion literally reads "produces a
`qpdf --qdf` normalization diff confined to the edited operators." Research measured this literally:
a whole-file `qpdf --qdf --object-streams=disable --no-original-object-ids` + `diff -a` on
`spike/fixtures/tj_refit_sample.pdf` (an 8-part `/Contents` array, one `Tj` string mutated)
produced **13,689 lines of diff** for a single-word edit -- pure object-renumbering noise from
`engine/identity_rewrite.py`'s own established pattern of coalescing `/Contents` into one stream,
which deletes N-1 indirect objects and shifts every subsequent object number. 52.5% of the corpus
(114/217 documents) has an array `/Contents`, so this is not an edge case. The criterion's *intent*
(the change is confined to the edited operators) is preserved here by a **targeted structural
comparison** -- decode and compare only the touched stream part's own operator list, old vs new,
via `pikepdf.parse_content_stream` on each -- never a whole-file text diff. This is recorded the
same way Phase 1 recorded its correction to "pixel-identical across all three engines": as a
documented, measured correction, not a silent reinterpretation.

**Assertion layering (ROADMAP.md, "corrected in Phase 1, plan 01-04").** Two engines rendering the
*same untouched page* disagree 0-98% purely from antialiasing/gamma/hinting -- that is why clause 5
(same-engine, zero tolerance) and clause 6 (cross-engine, `run_corpus_harness.py`'s measured
tolerance: 3px blur, 20/255 per-channel, 8% pixel-count threshold) are distinct checks, never
conflated. `harness/masked_diff.py::masked_pixel_diff` is the exact zero-tolerance primitive for
clause 5; `harness/run_corpus_harness.py::_cross_engine_pair_ok` is the exact tolerant primitive for
clause 6. Both are reused unmodified.

Purpose: retire Risk #1 (the unproven composition of fit + fonts + rewrite) for the simple,
no-substitution case, and gate whether the more expensive G2b work in 03-09 is worth attempting.

Output: `harness/structural_diff.py` (new, reusable verification primitive), its unit tests, and
`tests/test_gate_g2a.py::test_confined_diff_isolated_to_edited_stream` -- the single pinned gate
test asserting all six clauses from one real pipeline run.
</objective>
