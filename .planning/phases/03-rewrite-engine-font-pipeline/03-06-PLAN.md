<objective>
Build `engine/rewrite.py`: the module that actually performs a text edit inside a real PDF's
content stream, using instruction identity rather than byte ranges, and never reshaping
`/Contents`. This is the module `engine/identity_rewrite.py`'s own docstring names as the one that
crosses its boundary ("ZERO width-fitting, ZERO font subsetting, ZERO glyph substitution, ZERO
TJ-array arithmetic" -- Phase 3 is the phase that does all four). Phase 2's own CONTEXT.md already
named this coupling: "the run model and the rewrite engine are therefore coupled, and Phase 3
inherits this."

**Architecture decision this plan makes (Claude's Discretion, per 03-CONTEXT.md):** the
correlation bridge 03-02 built and corpus-validated (`touched_instruction_indices`) lives in
`spike/instruction_correlation_probe.py`. `engine/` imports nothing from `spike/` anywhere in this
codebase today (verified directly), matching `spike/tj_refit_prototype.py`'s own established
throwaway posture ("absorb, rewrite, or leave alone"). This plan therefore **ports** the algorithm
verbatim into `engine/rewrite.py` rather than importing across that boundary -- same corpus-proven
logic, self-contained `engine/`, zero re-derivation or re-measurement of what 03-02 already proved.

**Module shape, built in three layers so each task hands the next a clean seam (interface-first):**
1. `rewrite_instructions` -- the low-level splice primitive: given a run and an already-built
   `list[pikepdf.ContentStreamInstruction]` to install, correlate, replace the first touched
   instruction's slot with that list, delete every other touched instruction by index, write back
   without ever reshaping `/Contents`.
2. `rewrite_run` -- the public entry point. Takes `new_text` + a `FitResult` + an optional
   already-built substitution target, builds the right instruction list (Tz-bracketed and/or
   Tf-bracketed as needed) by calling layer 1, then runs D-04's runtime matrix guard.
3. The two operand-resolution branches inside `rewrite_run`: substituted (via 03-05's
   `shape_cids`/`embed_type0_font`) and non-substituted (via the run's own original font
   encoding).

Purpose: this is Gate G2a/G2b's actual mechanism -- the module that makes "replace text and have
the output look like nothing happened" literally true at the byte level.

Output: `engine/rewrite.py`, `tests/test_rewrite.py`, `engine/classify_run.py` (promoted helper),
`engine/identity_rewrite.py` (updated import).
</objective>
