<objective>
Prove Gate G2b -- THE PROJECT GATE: replacing a run with text containing a character genuinely
absent from its own embedded font subset, forcing the full substitution pipeline (03-04's
`run_needs_substitution` trigger -> 03-05's subset/embed -> 03-06's substituted-run content-stream
surgery -> 03-07's recipe orchestration) to execute end to end for the first time in this phase.
03-08 already proved the simpler no-substitution branch; this plan is its substitution-path
counterpart and the phase's terminal deliverable.

**Per D-15, this plan gates on two distinct evidence classes.** CI-automatable (built and run by
this plan, Tasks 1-2): OTS validation of the emitted font, `qpdf --check` clean, same-engine
zero-tolerance pixel diff outside the substituted run, cross-engine agreement within the measured
tolerance, and a programmatic `/ToUnicode` extraction round-trip -- the copy-paste proxy.
Recorded-once (documented and produced by this plan, performed by a human, Task 3): the three
real-viewer opens (Acrobat Reader, macOS Preview, Chrome) with no repair prompt, the Acrobat
copy-paste Unicode check, and D-08's rendered before/after contact-sheet seam review across corpus
samples -- following the `PLAYA-DECISION.md`/`TJ-REFIT-RESULTS.md` precedent this project already
established in Phase 1.

**Why the forcing fixture is found live, never hand-picked.** A specific document/character pair
that triggers substitution today is a fact about that document's embedded subset, not something
safe to assert by construction. `harness/g2b_fixture.py` (Task 1) proves the trigger fires via a
real `plan_recipe` dry run before either the gate test or the manual-verification artifacts ever
use it -- the same "measure, then pin" discipline this codebase already applies to every other
threshold.

Purpose: retire Risk #1 for the case that actually matters -- the character the document never
contained -- and unblock Phase 4 onward, which does not begin until this gate passes (ROADMAP.md;
CLAUDE.md's "no web-tier work before G2b" constraint).

Output: `harness/g2b_fixture.py` (the substitution-forcing fixture finder and D-08 contact-sheet
generator, reused by both the gate test and the manual-verification checkpoint),
`tests/test_gate_g2b.py::test_g2b_full_pipeline` (VALIDATION.md's pinned G2b gate test), and
`G2B-GATE-RESULTS.md` (the recorded manual evidence). With this plan, Phase 3's full requirement
set -- EDIT-02, EDIT-03, EDIT-04, FONT-01 through FONT-06 -- is covered across all 9 plans.
